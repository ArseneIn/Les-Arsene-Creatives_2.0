
To make the Annual Reports downloadable on the Resources page, please place the PDF files in this directory with the following filenames:

1. 2024 Annual Report -> annual-report-2024.pdf
2. 2023 Annual Report -> annual-report-2023.pdf
3. 2022 Annual Report -> annual-report-2022.pdf
4. 2021 Annual Report -> annual-report-2021.pdf

Once these files are placed here, the "Download" buttons on the Resources page will automatically work.
